# 物联网后端系统架构：从基础到AI驱动的未来

本书面向物联网后端开发人员和架构师，围绕设备接入、数据处理与存储、应用集成、架构设计及部署运维展开，并讨论 AI 在这些环节中的应用。读者可以按目录完整阅读，也可以从正在解决的问题切入。
